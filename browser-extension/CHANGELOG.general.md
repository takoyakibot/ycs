# 歌枠タイムスタンプ検出 変更履歴

Chrome Web Store で公開している一般版の、バージョンごとの変更点です。

## 0.1.0（初回公開）

- YouTube の動画ページで、動画全体を再生しながら音量を解析し、波形グラフ（音量ダイナミクス）を表示
- 再生リスト内の動画を順番にスキャンする自動スキャン
- 音量とチャットリプレイの拍手から楽曲の開始位置を推定し、タイムスタンプ候補を一括追加
- タイムスタンプエディタ（マーカーの追加・移動・削除、元に戻す／やり直し、N キーで再生位置に追加、コピー、クリップボードからの取り込み）
- 曲名候補の表示（字幕から推定、入力中の曲名のサジェスト）
- ポップアップでのスキャン済み動画の一覧・削除、グラフの高さ設定
