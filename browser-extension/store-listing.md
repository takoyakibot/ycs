## 1. ストア掲載情報（「ストアの掲載情報」タブ）

### タイトル
ZIP 内の `manifest.json` の `name` がそのまま使われる（ダッシュボードでは編集できない）。

```
歌枠タイムスタンプ検出（一般版）
```

### 概要（132文字以内）
`manifest.json` の `description` がそのまま使われる。

```
YouTube動画の音量変化を検出し、楽曲開始のタイムスタンプ候補を生成します
```

### 説明

```
歌枠タイムスタンプ検出は、歌枠配信のアーカイブで「何曲目が何分何秒から始まるか」のタイムスタンプ（曲目リスト）を作る作業を手助けする拡張機能です。動画ページに音量の波形グラフとタイムスタンプエディタを表示し、楽曲の開始位置の候補を自動で見つけます。

■ 主な機能

【音量スキャンと波形グラフ】
動画全体を再生しながら音量を解析し、プレーヤーの下に波形グラフを表示します。歌っている区間がひと目でわかり、グラフをクリックするとその位置へ移動できます。解析結果は動画ごとにブラウザ内へ保存されるので、次に開いたときはすぐにグラフが表示されます。再生リスト内の動画を順番にスキャンすることもできます。

【楽曲開始の自動検出】
音量の変化と、チャットリプレイの拍手（8888 や 👏 など）の集中から、楽曲が始まった位置を推定し、タイムスタンプ候補としてまとめて追加します。

【タイムスタンプエディタ】
マーカーの追加・移動・削除、元に戻す／やり直しに対応しています。再生中に N キーを押すと、その位置にマーカーを追加できます。完成したタイムスタンプはテキストとしてコピーでき、既存のタイムスタンプをクリップボードから取り込むこともできます。

【曲名候補】
マーカー付近の字幕から曲名の候補を表示します。曲名の入力中には候補をサジェストします。候補は「歌枠履歴er:D」（https://ycs.alpacasandbag.jp）の楽曲データベースから取得します。

■ ご利用にあたって
・アカウント登録やログインは不要です。
・音量の解析結果、タイムスタンプ、チャットリプレイはブラウザ内にのみ保存されます。
・曲名候補の取得のため、字幕の一部と入力中の曲名を歌枠履歴er:Dに送信します。個人を特定する情報は送信しません。
・詳しくはプライバシーポリシーをご確認ください。
```

## 2. プライバシーへの取り組み（「プライバシー」タブ）

### 単一用途の説明

```
YouTubeの歌枠配信アーカイブで、楽曲が始まる位置を見つけてタイムスタンプ（曲目リスト）を作成することを支援します。動画の音量とチャットリプレイから楽曲開始の候補を検出し、動画ページ上のエディタでタイムスタンプを編集・コピーできるようにします。
```

### 権限ごとの使用理由

**storage**

```
動画ごとの音量解析結果、編集中のタイムスタンプ、グラフの表示設定をブラウザ内に保存し、次回同じ動画を開いたときに復元するために使用します。
```

**ホスト権限 https://www.youtube.com/***

```
YouTubeの動画ページに波形グラフとタイムスタンプエディタを表示し、ページ内の動画の音量を解析するために使用します。また、拡張機能のポップアップで現在のタブがYouTubeの動画ページかどうかを判定するために、タブのURLを参照します。
```

### リモートコードの使用
いいえ

```
すべてのJavaScriptは拡張機能のパッケージに含まれています。page-bridge.js はパッケージに同梱したファイルで、字幕データを取得するためにYouTubeのページへ読み込みます。外部から取得したコードは実行しません。
```

## 4. スクリーンショット

1280x800（または 640x400）、1〜5枚。PNG または JPEG。初回は以下の3枚を用意する。

1. 歌枠アーカイブの動画ページで、スキャン済みの波形グラフとマーカーが並んでいる画面（主機能）
2. タイムスタンプエディタでマーカーの曲名欄に曲名候補が出ている画面
3. 拡張機能のポップアップ（スキャン済み一覧が表示されている状態）

撮影時の注意:
- 拡張の名前に「YouTube」を含めない方針のため、画像内にキャプションを入れる場合も YouTube のロゴを大きく扱わない
- チャット欄やコメント欄に他の視聴者の名前・アイコンが写らないようにする

小さいプロモーションタイル（440x280）は任意。
