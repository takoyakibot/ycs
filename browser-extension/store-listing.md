# Chrome Web Store 掲載情報

## タイトル（45文字以内）
歌枠タイムスタンプ検出 - 歌枠履歴er:D

## 短い説明（132文字以内）
YouTube歌枠配信の音量変化を解析し、楽曲開始のタイムスタンプ候補を自動生成。字幕からの楽曲検出にも対応。歌枠履歴er:Dと連携して楽曲情報を管理できます。

## 詳細な説明
歌枠タイムスタンプ検出は、YouTube歌枠配信（歌ってみた配信）のアーカイブからタイムスタンプを効率的に作成するためのChrome拡張機能です。

### 主な機能

**音量スキャン**
YouTube動画の音量変化をリアルタイムで解析し、楽曲の開始・終了ポイントの候補を自動検出します。検出結果は波形グラフとして視覚的に表示されます。

**字幕からの楽曲検出**
動画の字幕テキストを取得し、歌枠履歴er:Dの楽曲データベースと照合することで、演奏された楽曲を特定します。

**タイムスタンプエディタ**
検出されたタイムスタンプ候補をYouTube動画上で直接編集できます。マーカーの追加・削除・移動に対応し、最終的なタイムスタンプリストをクリップボードにコピーできます。

**歌枠履歴er:Dとの連携**
歌枠履歴er:D（ycs.alpacasandbag.jp）のAPIキーを設定することで、スキャン結果をサーバーに保存し、楽曲管理機能と連携できます。

### プライバシー
- 音量データはブラウザのローカルストレージにのみ保存されます
- 個人を特定できる情報は収集しません
- 詳細はプライバシーポリシーをご確認ください
