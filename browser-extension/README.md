# 歌枠タイムスタンプ検出

YouTube動画の音量変化を検出し、楽曲開始のタイムスタンプ候補を自動生成するChrome拡張機能です。

## 機能

### 楽曲開始検出
- YouTube動画の音声をリアルタイムでキャプチャ
- 無音/小音量から急に音量が上がった瞬間を検出
- 検出したタイムスタンプを一覧表示
- タイムスタンプをクリックで動画にシーク
- タイムスタンプ一覧をクリップボードにコピー

### 音量ダイナミクスグラフ
- 動画プレーヤー下部に音量の波形グラフを表示
- グラフをクリックして任意の位置にシーク
- 高速スキャン機能：高速再生で動画全体のグラフを生成
- リアルタイム描画：通常再生中も再生した部分のグラフを構築

## インストール方法（開発者モード）

1. Chromeで `chrome://extensions/` を開く
2. 右上の「デベロッパーモード」をONにする
3. 「パッケージ化されていない拡張機能を読み込む」をクリック
4. `browser-extension` ディレクトリを選択

## 使い方

### 楽曲開始検出
1. YouTubeの動画ページを開く
2. 拡張機能のアイコンをクリックしてポップアップを開く
3. 「検出開始」ボタンをクリック
4. 動画を再生すると、楽曲開始候補が自動的に検出される
5. 検出されたタイムスタンプは一覧に追加される
6. 「コピー」ボタンでタイムスタンプ一覧をコピー

### 音量ダイナミクスグラフ
1. YouTubeの動画ページを開く
2. 拡張機能のポップアップで「グラフ表示」ボタンをクリック
3. 動画プレーヤーの下にグラフが表示される
4. 「スキャン」ボタンで動画全体のグラフを素早く生成（高速再生）
5. グラフ上の任意の位置をクリックすると、その時間にジャンプ
6. オレンジ色のマーカーが現在の再生位置を示す

## 設定パラメータ

| パラメータ | 説明 | デフォルト |
|------------|------|------------|
| 音量しきい値 | これ以上の音量で「曲が始まった」と判定 | 0.15 |
| 静音しきい値 | これ以下の音量を「静かな状態」と判定 | 0.05 |
| 静音最小時間 | 曲開始と判定する前に必要な静かな時間（秒） | 1.0 |
| クールダウン | 連続検出を防ぐ待機時間（秒） | 3.0 |

## 注意事項

- `tabCapture` 権限が必要なため、拡張機能のポップアップから開始する必要があります
- 倍速再生でも正しいタイムスタンプが記録されます
- 楽曲の自動認識機能はありません（タイムスタンプ候補の生成のみ）

## ファイル構成

```
browser-extension/
├── manifest.json     # 拡張機能の設定
├── background.js     # Service Worker（音声キャプチャ・解析）
├── content.js        # YouTubeページに注入されるスクリプト
├── popup.html        # ポップアップUI
├── popup.js          # ポップアップのロジック
├── icons/
│   └── icon.svg      # アイコン（SVG原本）
└── README.md
```

## 技術スタック
