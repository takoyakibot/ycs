# 歌枠タイムスタンプ検出

YouTube動画の音量変化を検出し、楽曲開始のタイムスタンプ候補を自動生成するChrome拡張機能です。
歌枠履歴er:D との連携機能や、YouTube/Google検索の補助機能も搭載しています。

## 機能

### 楽曲開始検出（音量スキャン）
- YouTube動画の音声をリアルタイムでキャプチャ
- 無音/小音量から急に音量が上がった瞬間を検出
- 検出したタイムスタンプを一覧表示
- タイムスタンプをクリックで動画にシーク
- タイムスタンプ一覧をクリップボードにコピー

### 音量ダイナミクスグラフ
- YouTube動画プレーヤー下部に音量の波形グラフを表示
- グラフをクリックして任意の位置にシーク
- 高速スキャン機能：高速再生で動画全体のグラフを生成
- リアルタイム描画：通常再生中も再生した部分のグラフを構築
- **2窓リアルタイム同期**：別ウィンドウでスキャンしながら、もう一方でグラフを確認可能

### 楽曲開始の自動検出（候補マーカー一括生成）
- スキャン済みの音量データを解析し、楽曲開始らしい位置に候補マーカーを一括追加
- タイムスタンプエディタの「自動検出」ボタンから実行
- 平均音量ではなく「基準音量に近いサンプルの密度（活動率）」で判定するため、
  フレーズ間で音量が落ちる櫛状の波形になるアカペラ歌唱にも対応
- 閾値は配信ごと・時間帯ごとの音量差に自動追従（スライディング窓の局所基準音量）
- チャットの拍手バースト（8888・👏等の集中）で境界を補強
  （未取得なら自動で取得。チャットリプレイの無い動画では音量のみで判定）
  - 拍手なしの短いギャップ → 同一曲のブレイクとみなして結合
  - 区間内部の拍手 → 曲の切れ目とみなして分割（途切れず歌い続けるケース）
  - チャット送信の数秒の遅延は補正済み
- 既存マーカーの前後60秒以内にある候補はスキップ
- 追加した候補は通常のマーカーと同様に移動・削除・Undo（Ctrl+Z）が可能

### YouTube Liveチャット遅延送信
- チャット送信を設定秒数（3〜30秒）だけプールし、送信前にキャンセル可能
- 誤送信やタイポの防止に有用
- **AI毒性チェック**（オプション）：Claude APIを使用して送信前にメッセージの毒性を判定
- リプレイモードでは自動的に無効化

### Google検索 AI概要の非表示
- Google検索結果ページのAI概要（AI Overview / SGE）を非表示にする
- ポップアップのチェックボックスでON/OFF切替

### 歌枠履歴er:D 管理画面連携
- ycs管理画面のアーカイブ一覧でスキャン済みアーカイブを視覚的に表示
- スキャン進捗率（%）の表示
- 字幕データの自動送信（YCS API連携）

### 字幕データ取得（page-bridge）
- YouTubeの字幕（timedtext）データをページコンテキストから取得
- fetch/XHRをインターセプトして字幕レスポンスをキャッシュ
- Content Scriptからのリクエストに応じてキャッシュデータを提供

### ハイライト検出（AI判定）
- 音量・字幕・チャットの3シグナルを歌枠履歴er:DのAPIに送信
- サーバー側で機械的に候補区間を抽出し、Claude (Haiku) でラベル付け
- 候補一覧をパネルに表示、クリックでその時刻にシーク
- API: `POST /api/extension/highlights/detect` (Sanctumトークン認証)
- 事前に音量スキャン・字幕取得・チャット取得を済ませておくと検出精度が上がる

## インストール方法（開発者モード）

1. Chromeで `chrome://extensions/` を開く
2. 右上の「デベロッパーモード」をONにする
3. 「パッケージ化されていない拡張機能を読み込む」をクリック
4. `browser-extension` ディレクトリを選択

## 使い方

### 楽曲開始検出（音量スキャン）
1. YouTubeの動画ページを開く
2. 拡張機能のポップアップで「スキャン開始」ボタンをクリック
3. 高速再生で動画全体の音量データを収集
4. スキャン済みデータはポップアップの一覧に保存される

### 音量ダイナミクスグラフ
1. YouTubeの動画ページを開く
2. ポップアップで「YouTube画面にUIを表示」をONにする
3. 動画プレーヤーの下にグラフが表示される
4. 「スキャン」ボタンで動画全体のグラフを素早く生成（高速再生）
5. グラフ上の任意の位置をクリックすると、その時間にジャンプ
6. オレンジ色のマーカーが現在の再生位置を示す

### 2窓でスキャンしながら確認する
1. ウィンドウAで動画を開き、「スキャン」を開始
2. ウィンドウBで同じ動画を開き、グラフ表示をONにする
3. ウィンドウAのスキャン進捗がリアルタイムでウィンドウBに反映される
4. ウィンドウBでグラフを見ながら、気になる位置をクリックして確認

### チャット遅延送信
1. ポップアップで「チャット遅延送信」をONにする
2. 遅延秒数をスライダーで調整（3〜30秒、デフォルト10秒）
3. YouTube Liveのチャットで送信すると、設定秒数後に自動送信される
4. 遅延中に表示されるキャンセルボタンで送信を中止可能

### 音量グラフの高さ設定
1. ポップアップの「音量グラフ設定」で「初期の高さ」と「拡大1段階あたり」の増分（px）を指定
2. 変更は開いているYouTubeタブに即時反映される（既定: 60px / 20px）

### YCS API連携
1. ポップアップの「YCS API設定」でAPIトークンを設定（サーバーURLは既定で `https://ycs.alpacasandbag.jp`）
2. 字幕データの自動送信が有効になる
3. ローカル環境に送信する場合はサーバーURLを `http://localhost:8000` などに変更する

## 設定パラメータ

| パラメータ | 説明 | デフォルト |
|------------|------|------------|
| 音量しきい値 | これ以上の音量で「曲が始まった」と判定 | 0.15 |
| 静音しきい値 | これ以下の音量を「静かな状態」と判定 | 0.05 |
| 静音最小時間 | 曲開始と判定する前に必要な静かな時間（秒） | 1.0 |
| クールダウン | 連続検出を防ぐ待機時間（秒） | 3.0 |

## 注意事項

- `tabCapture` 権限が必要なため、拡張機能のポップアップから操作を開始する必要があります
- 倍速再生でも正しいタイムスタンプが記録されます
- 楽曲の自動認識機能はありません（タイムスタンプ候補の生成のみ）
- チャット遅延送信はライブ配信中のみ有効（リプレイでは無効）
- AI毒性チェックにはClaude APIキーが必要

## エディション

本拡張は**管理者版**と**一般版**の2つのエディションでビルドされる。

### 管理者版
- `manifest.json` を使用
- background（Service Worker）・offscreen を含む全機能が有効
- tabCapture による音声キャプチャ、Claude API 毒性チェック、YCS API 連携（トークン認証）等

### 一般版
- `manifest.general.json` を使用
- background（Service Worker）を持たない
- 管理者向け機能（tabCapture スキャン、チャット遅延送信、Google AI概要非表示、Claude API、YCS APIトークン連携）はビルド時に除去される
- Chrome Web Store に限定公開

### ビルドの仕組み

管理者向けのコード・UIは実行時に隠すのではなく、**ビルド時に一般版の成果物から物理的に除去**される。

- `content-general.js`: `src/content/index-general.js` を rollup でバンドル。管理者専用モジュールは `rollup.config.mjs` の `generalStubs` でスタブに差し替え。共有モジュール内の管理者向け分岐は `src/content/edition.js` の `IS_GENERAL_EDITION` で書き、一般版ビルドでは `edition-general.js`（`true`）に差し替わるため tree-shaking で消える
- `popup-general.js`: `popup.js` の `IS_GENERAL_EDITION` 判定を `true` に置き換えてバンドル
- `popup-general.html`: `popup.html` から `data-admin-only` 属性の付いた要素と HTML コメントを除去
- `page-bridge.js`: ビルドを通らずそのままコピー

ビルドコマンド:

```bash
cd browser-extension && bash build.sh
```

## ファイル構成

```
browser-extension/
├── manifest.json              # 管理者版の設定（Manifest V3）
├── manifest.general.json      # 一般版の設定（background なし）
├── background.js              # Service Worker（管理者版のみ: 音声キャプチャ制御・メッセージハブ）
├── offscreen.html             # Offscreen Document（管理者版のみ）
├── offscreen.js               # Offscreen音声処理（管理者版のみ: Web Audio APIによる音量解析）
├── content.js                 # 管理者版 Content Script（ビルド生成物）
├── content-general.js         # 一般版 Content Script（ビルド生成物）
├── content-chat-delay.js      # YouTubeチャット遅延送信（管理者版のみ）
├── content-google.js          # Google検索AI概要非表示（管理者版のみ）
├── content-ycs.js             # ycs管理画面連携（管理者版のみ）
├── page-bridge.js             # ページコンテキスト字幕データ取得ブリッジ
├── popup.html                 # 管理者版ポップアップUI
├── popup.js                   # 管理者版ポップアップのロジック
├── popup-general.html         # 一般版ポップアップUI（ビルド生成物）
├── popup-general.js           # 一般版ポップアップのロジック（ビルド生成物）
├── rollup.config.mjs          # Rollup ビルド設定
├── build.sh                   # ビルド・パッケージングスクリプト
├── src/content/               # Content Script のソース（モジュール分割）
│   ├── index.js               # 管理者版エントリポイント
│   ├── index-general.js       # 一般版エントリポイント
│   ├── edition.js             # エディション判定（管理者版: false）
│   └── edition-general.js     # エディション判定（一般版: true）
├── icons/
│   └── icon.svg               # アイコン（SVG原本）
└── README.md
```

## 技術スタック

- Chrome Extension Manifest V3
- Web Audio API（音声解析）
- tabCapture API（タブ音声キャプチャ、管理者版のみ）
- Offscreen Documents API（バックグラウンド音声処理、管理者版のみ）
- Anthropic Claude API（毒性チェック、管理者版のみ・オプション）
